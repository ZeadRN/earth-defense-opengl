# Celestial surface maps

## Earth

NASA Earth Observatory, Blue Marble: Next Generation, July 2004 base map.
Credit: Reto Stockli, NASA Earth Observatory / NASA Goddard Space Flight Center.

- Source: https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/
- Download: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/bmng/bmng-base/july/world.200407.3x5400x2700.jpg
- Local asset: `assets/earth.rgbz`.
- Preparation: resized from 5400 x 2700 to 2048 x 1024, converted to RGB, rows flipped for OpenGL texture coordinates, losslessly compressed with zlib.

## Moon

NASA's Scientific Visualization Studio, CGI Moon Kit, LROC color map.
Credit: NASA's Scientific Visualization Studio; Ernie Wright (USRA); Noah Petro (NASA/GSFC). Underlying imagery: Lunar Reconnaissance Orbiter / LROC instrument team.

- Source: https://svs.gsfc.nasa.gov/4720/
- Original map: https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/lroc_color_2k.jpg
- Download mirror used because the NASA asset server timed out: https://github.com/sudoaanish/COSMOS/blob/master/assets/textures/moon-lroc-2k.jpg
- Mirror provenance: https://github.com/sudoaanish/COSMOS/blob/master/assets/textures/ATTRIBUTION.md
- Local asset: `assets/moon.rgbz`.
- Preparation: 2048 x 1024 map converted to RGB, rows flipped for OpenGL texture coordinates, losslessly compressed with zlib.

The maps retain their source attribution and are not original artwork by the project contributors. NASA media guidance: https://www.nasa.gov/nasa-brand-center/images-and-media/ .

## Rendering

The starfield is generated by this project's code, not an astronomical catalog. The atmosphere is a visual approximation. The Moon's size is approximately proportional to Earth, but its orbital distance and motion are compressed for gameplay. These visuals are not a scientific simulation.

## Asset format

Each `.rgbz` file has an 8-byte header: width and height as two little-endian unsigned 32-bit integers. The remaining bytes are zlib-compressed RGB pixels, with the bottom image row first. The game loads these using Python's standard library; no Pillow installation or network download is needed at runtime.
